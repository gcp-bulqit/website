## Outline

- **The problem:** high-risk operations that lived in one person's head.
- **Approval gates:** blue/green promotion pre-flight, merge trains with migration renumbering, and Twilio number provisioning.
- **Content syncs that respect production:** checkpoint-based syncs between dev and production databases and CMS that never overwrite production edits.
- **Results:** 146 notification templates reconciled, and 23 broken images a naive copy would have caused, avoided.
- **Writing a skill a teammate (or an agent) can trust.**
